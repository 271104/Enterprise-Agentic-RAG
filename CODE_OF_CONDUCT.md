# Contributor Code of Conduct

## Our standard

Participants are expected to be respectful, constructive, and considerate. Harassment, discrimination, personal attacks, and deliberate disruption are not acceptable.

## Scope and enforcement

This applies to project spaces and public interactions when someone is representing the project. Project maintainers may remove content or restrict participation when conduct violates this standard. Report concerns privately to the maintainers using the contact method in the repository profile.

This short policy is intended to set basic expectations; maintainers should publish a named contact and a fuller enforcement process before inviting a broad community.
